// Cómo se hace, de verdad, una web agéntica

          
Se construye por andenes

          

            
3
 Confiable
Valida en código · confirma lo irreversible · marca el contenido de terceros.

            
2
 Accionable
Una tool de WebMCP por intención real: buscar, agregar, reservar.

            
1
 Legible
HTML semántico y accesible: lo que sirve a un lector de pantalla, sirve a un agente.

          

        

        

      


      
      

        

          
// Hoy, con el Origin Trial

          
Cinco cosas que ya puedes hacer

          

            
Agentes del navegador
Usan tu sitio sin scraping. Prueba con Model Context Tool Inspector.

            
Tu asistente in-page
Gemini Nano (Prompt API): sin servidor, sin API key, datos en el equipo.

            
Voz y accesibilidad
“Agrega lo de siempre” = 1 tool, no 12 clics.

            
QA y debugging
annotations.debugging para que tu agente de código vea el estado.

            
Widgets de otros orígenes
Un iframe con allow="tools" expone tools con exposedTo.

Tu web agéntica en 5 postas

          

            

            

            

              
1Inventario de intenciones¿Qué viene a hacer la gente?

5Mide con evalslínea base, ideal y checks
